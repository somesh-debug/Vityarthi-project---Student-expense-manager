# Project Statement

## Problem Statement
College students make many small daily payments for food, travel, stationery, entertainment and other needs. When these expenses are not recorded systematically, it becomes difficult to know where money is being spent.

## Scope
The Student Expense Manager provides a simple local application for recording and managing personal student expenses. It focuses on basic expense management and summary analysis.

## Target Users
- College students
- Hostel students
- Students who want to track daily spending

## High-Level Features
1. Expense entry and storage
2. Expense viewing, updating and deletion
3. Total and average expense calculation
4. Category-wise spending analysis
5. Input validation and error handling
